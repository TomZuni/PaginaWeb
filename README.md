# Tienda Gamer - PFY2201 Semana 6

Proyecto de optimización de lógica y rendimiento con JavaScript.

## Páginas
- `index.html`: inicio y navegación.
- `productos.html`: catálogo dinámico con Fetch API, búsqueda por `submit`, carrito y manipulación del DOM mediante `click`.
- `contacto.html`: formulario con evento `submit` y validación.

## Estructura
- `assets/css/estilos.css`
- `assets/js/script.js`
- `assets/img/`
- `juegos.json`

## Ejecución
Abrir con Live Server para que Fetch API pueda leer `juegos.json` correctamente.
